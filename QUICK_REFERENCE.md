# Quick Reference Guide

## 🚀 Quick Start Commands

```bash
# Setup (first time only)
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Run complete pipeline
python scripts/run_elt_pipeline.py

# Run individual layers
python scripts/bronze_layer.py
python scripts/silver_layer.py
python scripts/gold_layer.py
```

## 📊 Layer Cheat Sheet

| Layer | Purpose | Input | Output | Key Actions |
|-------|---------|-------|--------|-------------|
| 🥉 **Bronze** | Store raw data | Raw CSV files | bronze_*.csv | Add metadata, preserve all |
| 🥈 **Silver** | Clean data | Bronze layer | silver_*.csv | Dedupe, validate, standardize |
| 🥇 **Gold** | Business metrics | Silver layer | gold_*.csv | Aggregate, join, calculate KPIs |

## 🔍 Common Python Commands

```python
import pandas as pd

# Load data
df = pd.read_csv('data/bronze/bronze_sales.csv')

# Explore data
df.head()           # First 5 rows
df.info()           # Data types and null counts
df.describe()       # Statistical summary
df.shape            # (rows, columns)
df.columns          # Column names

# Data quality checks
df.isnull().sum()   # Count nulls per column
df.duplicated().sum()  # Count duplicates
df['column'].value_counts()  # Frequency counts

# Basic transformations
df.dropna()         # Remove rows with nulls
df.drop_duplicates()  # Remove duplicate rows
df.fillna(0)        # Fill nulls with 0
```

## 💡 Key Concepts

### Bronze Layer
- ✅ Preserve raw data exactly as received
- ✅ Add ingestion timestamp and source metadata
- ❌ No transformations or filtering
- ❌ Never delete Bronze data

### Silver Layer
- ✅ Remove duplicates
- ✅ Handle missing values
- ✅ Standardize formats (dates, text)
- ✅ Validate data types
- ✅ Apply business rules

### Gold Layer
- ✅ Join multiple sources
- ✅ Calculate KPIs and metrics
- ✅ Create aggregations
- ✅ Optimize for reporting
- ✅ Apply business logic

## 🐛 Troubleshooting

| Problem | Solution |
|---------|----------|
| `ModuleNotFoundError` | Activate venv and run `pip install -r requirements.txt` |
| `FileNotFoundError` | Run from project root directory |
| Silver/Gold fails | Run Bronze layer first |
| Permission denied | Check file permissions |

## 📊 Output Files

### Bronze Layer (3 files)
- `bronze_sales.csv` - All sales transactions + metadata
- `bronze_customers.csv` - All customers + metadata
- `bronze_products.csv` - All products + metadata

### Silver Layer (3 files)
- `silver_sales.csv` - Cleaned sales with total_amount
- `silver_customers.csv` - Validated customers
- `silver_products.csv` - Products with profit_margin

### Gold Layer (4 files)
- `gold_sales_summary.csv` - Revenue by category
- `gold_customer_metrics.csv` - Customer lifetime value
- `gold_product_performance.csv` - Product rankings
- `gold_daily_sales_trend.csv` - Time-series metrics
